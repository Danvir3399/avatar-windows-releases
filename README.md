# VARYA AVVA для Windows

Готовые выпуски приложения с локальными аватарами и эфирным окном для OBS. Обработка изображения работает на компьютере; интернет нужен для проверки и скачивания обновлений.

Текущая версия: **[0.3.3](https://github.com/Danvir3399/avatar-windows-releases/releases/tag/v0.3.3)**. Этот репозиторий содержит установщики, модели и документацию по установке.

В 0.3.3 приложение переименовано в VARYA AVVA; исправлена загрузка текстур красной шубы в Windows. Имена файлов установочного комплекта начинаются с `Avatar` для совместимости с прежними версиями механизма обновления.

## Первоначальная установка

Нужна 64-разрядная Windows; сборка проверена на Windows 10 x64. На диске установки должно быть не менее 8 ГБ свободного места, дополнительно нужен установочный комплект около 3 ГБ. Для сборки архива из скачанных частей временно понадобится ещё около 3 ГБ. Для фотоаватара нужна совместимая NVIDIA с драйвером; проверена GTX 1070 8 ГБ. Режим 3D доступен без подходящей CUDA. Python, Node.js и Codex устанавливать не требуется.

Для установки нужны два файла в одной папке:

- [Avatar-Setup-0.3.3-x64.exe](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.3/Avatar-Setup-0.3.3-x64.exe).
- `Avatar-Data-0.3.0-x64.7z`. Прежний полный архив данных подходит: версия 0.3.3 использует те же модели.

Если полного архива ещё нет, скачайте в эту же папку все три части:

1. [Avatar-Data-0.3.0-x64.7z.part01](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.3/Avatar-Data-0.3.0-x64.7z.part01).
2. [Avatar-Data-0.3.0-x64.7z.part02](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.3/Avatar-Data-0.3.0-x64.7z.part02).
3. [Avatar-Data-0.3.0-x64.7z.part03](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.3/Avatar-Data-0.3.0-x64.7z.part03).

Сохраните имена без добавленного браузером «(1)». Откройте эту папку в Проводнике, введите `powershell` в адресной строке и нажмите Enter. Вставьте весь блок: он соединит части в полный архив и не перезапишет уже существующий файл.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $avatarFolder = (Get-Location).ProviderPath
    $avatarParts = 1..3 | ForEach-Object {
        Join-Path $avatarFolder ('Avatar-Data-0.3.0-x64.7z.part{0:D2}' -f $_)
    }
    foreach ($avatarPart in $avatarParts) {
        if (-not (Test-Path -LiteralPath $avatarPart -PathType Leaf)) {
            throw "Не найдена часть: $avatarPart"
        }
    }
    $avatarArchive = Join-Path $avatarFolder 'Avatar-Data-0.3.0-x64.7z'
    $avatarOutput = [IO.File]::Open($avatarArchive, [IO.FileMode]::CreateNew, [IO.FileAccess]::Write)
    try {
        foreach ($avatarPart in $avatarParts) {
            $avatarInput = [IO.File]::OpenRead($avatarPart)
            try { $avatarInput.CopyTo($avatarOutput) }
            finally { $avatarInput.Dispose() }
        }
    }
    finally { $avatarOutput.Dispose() }
}
```

Дождитесь возвращения приглашения PowerShell. Запустите `Avatar-Setup-0.3.3-x64.exe` и пройдите мастер установки. Архив вручную распаковывать не нужно; установщик проверит его целостность и распакует модели. Это может занять несколько минут. Если у вас уже был полный архив, соединять части повторно не требуется.

Откройте **VARYA AVVA** через ярлык на рабочем столе или в меню «Пуск».

При первом запуске выбраны раздельный захват и «Дед Мороз (красный)», включена разметка на камере и вид «Рядом». Сохранённые настройки прежней установки сохраняются; новые значения доступны через «Сброс настроек» → «Вернуть настройки по умолчанию». Установщик пока без сертификата издателя Windows. Подпись описания обновления Ed25519 проверяется самим приложением и не заменяет сертификат Windows.

Названия образов: «Дед Мороз (красный)», «Дед Мороз (классический)», «Дед Мороз (сказочный)» и «Дед Мороз (праздничный)». Для проверки мимики отдельно доступен тестовый аватар.

## Обновления внутри программы

Если установлена **0.3.0 или 0.3.1**, один раз установите **0.3.3** поверх неё обычным установщиком. Настройки сохранятся. В 0.3.0 ещё нет механизма обновления; в 0.3.1 была ошибка перенаправлений GitHub, исправленная в 0.3.2.

Начиная с 0.3.2:

1. Откройте **Обновления → Проверить обновления**. Проверка также выполняется при запуске и раз в 6 часов.
2. При появлении новой версии нажмите **Обновить**. Программа скачает и проверит файлы, сама соединит части архива; прерванная загрузка продолжается с сохранённого места.
3. Завершите звонок и запись, нажмите **Установить и перезапустить** и подтвердите установку. Программа закроется и запустится снова с сохранёнными настройками.

Для обновлений из приложения вручную скачивать установщик и соединять части не нужно. Без подтверждения установка и перезапуск не выполняются. Недоступность GitHub не мешает локальной работе.

## Передача аватара в видеозвонок

1. В VARYA AVVA настройте камеру, персонажа и фон. Нажмите **Открыть эфирное окно**.
2. В отдельно установленной [OBS Studio](https://obsproject.com/download) добавьте источник **Захват окна**, выберите **VARYA AVVA — эфир** и нажмите **Запустить виртуальную камеру**.
3. В Телемосте или другой программе звонков выберите **OBS Virtual Camera**, для звука — свой микрофон.

Во время звонка оставьте VARYA AVVA, эфирное окно и OBS открытыми. Эфирное окно держите развёрнутым. Собственная системная виртуальная камера в комплект VARYA AVVA не входит.

Настройки хранятся в `%APPDATA%\VARYA\Avatar` и сохраняются при обновлении и удалении программы.
