# VARYA AVVA для Windows

Локальные аватары для видеозвонков с эфирным окном для OBS. Обработка изображения работает на компьютере; интернет нужен для проверки и скачивания обновлений.

Текущая версия: **[0.3.9](https://github.com/Danvir3399/avatar-windows-releases/releases/tag/v0.3.9)**.

## Если программа уже установлена

Начиная с версии **0.3.2**:

1. Откройте **Обновления → Проверить обновления → Обновить**.
2. Завершите звонок и запись, нажмите **Установить и перезапустить** и подтвердите установку.

В 0.3.7 исправлены ошибки обновления старых установок. Дождитесь завершения в окне хода обновления. Если Windows запросит права администратора для папки Program Files, нажмите **Да**. При прежней ошибке достаточно повторить обновление после выхода исправления: проверенные загруженные части используются повторно.

С 0.3.5 работают лёгкие обновления. Программа проверяет установленные файлы и скачивает только недостающие части программы, аватаров и фонов. Неизменившиеся модели и локальный движок повторно не скачиваются. В проверке перехода 0.3.4 → 0.3.5 потребовалось около **1,8 МБ** вместо полного комплекта. Размер следующих обновлений зависит от изменений; новая большая модель потребует загрузки этой модели.

Настройки сохраняются. Прерванная загрузка продолжается с сохранённого места. Проверка также выполняется при запуске и раз в 6 часов; установка и перезапуск выполняются после подтверждения. Недоступность GitHub не мешает локальной работе. Для 0.3.0–0.3.1 один раз используйте первоначальную установку ниже.

## Первоначальная установка

Нужна 64-разрядная Windows; сборка проверена на Windows 10 x64. На диске установки требуется не менее 8 ГБ свободного места, дополнительно нужен установочный комплект около 3,5 ГБ. Соединение частей архива временно занимает ещё около 3 ГБ. Для фотоаватара нужна совместимая NVIDIA с драйвером; проверена GTX 1070 8 ГБ. Без подходящей CUDA доступен 3D-режим. Отдельные Python, Node.js и Codex не нужны.

Сохраните в одну папку:

- [VARYA-AVVA-Full-Setup-0.3.9-x64.exe](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.9/VARYA-AVVA-Full-Setup-0.3.9-x64.exe).
- Полный архив `Avatar-Data-0.3.0-x64.7z`. Если он уже есть, повторно скачивать не нужно.

Если архива нет, скачайте все три части в эту же папку:

1. [Avatar-Data-0.3.0-x64.7z.part01](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.3/Avatar-Data-0.3.0-x64.7z.part01).
2. [Avatar-Data-0.3.0-x64.7z.part02](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.3/Avatar-Data-0.3.0-x64.7z.part02).
3. [Avatar-Data-0.3.0-x64.7z.part03](https://github.com/Danvir3399/avatar-windows-releases/releases/download/v0.3.3/Avatar-Data-0.3.0-x64.7z.part03).

Сохраните исходные имена файлов без добавленного браузером «(1)». Для соединения частей откройте папку в Проводнике, введите `powershell` в адресной строке, нажмите Enter и вставьте весь блок:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $avatarFolder = (Get-Location).ProviderPath
    $avatarParts = 1..3 | ForEach-Object {
        Join-Path $avatarFolder ('Avatar-Data-0.3.0-x64.7z.part{0:D2}' -f $_)
    }
    foreach ($avatarPart in $avatarParts) {
        if (-not (Test-Path -LiteralPath $avatarPart -PathType Leaf)) {
            throw "Не найдена часть: $avatarPart"
        }
    }
    $avatarArchive = Join-Path $avatarFolder 'Avatar-Data-0.3.0-x64.7z'
    $avatarOutput = [IO.File]::Open($avatarArchive, [IO.FileMode]::CreateNew, [IO.FileAccess]::Write)
    try {
        foreach ($avatarPart in $avatarParts) {
            $avatarInput = [IO.File]::OpenRead($avatarPart)
            try { $avatarInput.CopyTo($avatarOutput) }
            finally { $avatarInput.Dispose() }
        }
    }
    finally { $avatarOutput.Dispose() }
}
```

Дождитесь возвращения приглашения PowerShell. Запустите **VARYA-AVVA-Full-Setup-0.3.9-x64.exe** и пройдите мастер установки. Архив вручную распаковывать не нужно. Если полный архив был готов, соединение частей пропустите.

Небольшой `Avatar-Setup-0.3.9-x64.exe`, маленький `Avatar-Data-0.3.9-x64.7z.part01` и файлы `AVVA-Blocks`/`AVVA-Files` предназначены для автоматического обновления установленной программы. Для первой установки нужен именно **Full-Setup** и большой архив **0.3.0**.

Откройте **VARYA AVVA** через ярлык. При первом запуске выбраны раздельный захват, «Дед Мороз (красный)» и разметка на камере. В списке доступны также классический, сказочный, праздничный, красный 2, красный 3, красный HD, **красный 4** и тестовый аватар мимики. Прежние настройки сохраняются; вернуть начальные можно через **Сброс настроек → Вернуть настройки по умолчанию**.

## Красный 4 и управление пальцами

После обновления до 0.3.9 откройте **Настройки → Аватар → Персонаж → Дед Мороз (красный 4)**. Новая модель доступна в раздельном и проверенном режимах; текущий персонаж автоматически не меняется.

Для пальцев выберите **Захват → Раздельный**, включите **Движения кистей** и используйте переключатель **Движения пальцев**. При выключенных пальцах кисть продолжает поворачиваться, а пальцы возвращаются в исходное положение. Выбор сохраняется после перезапуска.

Отдельные пальцы поддерживают **красный 4** и **тестовый аватар (мимика)**. У остальных нынешних Дедов Морозов варежки поворачиваются целиком; рядом с недоступным переключателем показано пояснение. Разметка камеры продолжает показывать распознанные пальцы независимо от передачи движений модели.

При первом получении красного 4 обновление скачает новую модель. Уже установленные персонажи и большой нейросетевой движок повторно не загружаются.

## Частота кадров, полный экран и буфер

Под предпросмотром в блоке **Эфир в OBS и созвоны → Частота кадров** выберите **10, 15, 20, 24, 25, 30, 50 или 60 кадров/с**. По умолчанию — 30. Настройка сохраняется и применяется сразу к камере, обработке, превью, эфиру и записи. Во время записи её тоже можно менять.

Меньшая частота снижает нагрузку. Под превью показаны **Вывод** (фактическая частота и выбранный предел) и **захват** (скорость распознавания). Если камера или компьютер не успевают, фактическая частота ниже заданной. В раздельном режиме тело, лицо и кисти продолжают обрабатываться независимо, без накопления очереди кадров.

Под предпросмотром нажмите **Превью на весь экран** или **Эфир на весь экран**. Заголовок окна и панель задач Windows скрываются. В эфире остаются только аватар и фон.

Для отдельного монитора откройте обычное эфирное окно, перенесите его на нужный экран и нажмите **F11** либо дважды щёлкните по изображению. **Esc** возвращает обычное окно; F11 также переключает режим.

В блоке **Эфир в OBS и созвоны → Буфер кадров** по умолчанию выбрано **5 кадров**. Буфер применяется к готовому превью, записи и эфиру, добавляя примерно 0,17 с при 30 кадрах/с или 0,33 с при 15 кадрах/с. При меньшей фактической частоте задержка увеличивается. Для минимальной задержки выберите **Выключен**. Настройка сохраняется.

## Передача аватара в видеозвонок

1. Выберите камеру, аватар и фон. Нажмите **Открыть эфирное окно**.
2. В отдельно установленной [OBS Studio](https://obsproject.com/download) добавьте **Захват окна**, выберите **VARYA AVVA — эфир** и нажмите **Запустить виртуальную камеру**.
3. В Телемосте или другой программе выберите **OBS Virtual Camera**, для звука — свой микрофон.

Во время звонка оставьте VARYA AVVA, эфирное окно и OBS открытыми; эфирное окно держите развёрнутым. Настройки хранятся в `%APPDATA%\VARYA\Avatar`. Собственная системная виртуальная камера в комплект не входит. Описание обновления проверяется подписью Ed25519; установщик пока без сертификата издателя Windows.
